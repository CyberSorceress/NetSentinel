Recommended Incident Response Actions
  1. Port Scanning Mitigation: Block or rate-limit IPs engaging in horizontal scanning using dynamic firewall (iptables/nftables) rules.
  2. SYN Flood Defense: Enable SYN cookies (sysctl -w net.ipv4.tcp_syncookies=1) and TCP SYN rate-limiting.
  3. Cleartext Protocols: Disable unencrypted services (Telnet port 23, cleartext HTTP port 80, FTP port 21) in favor of SSH and TLS 1.3.
  4. DNS Inspection: Enforce DNS query size limits and block resolution of suspicious high-entropy subdomains indicative of exfiltration.
